# وَرَتِّلِ الْقُرْآنَ تَرْتِيلًا

نسخة تأسيسية (MVP) لتطبيق ويب عربي (PWA) لتسميع القرآن، مبني بـ React + Vite + TypeScript، مع مزامنة اختيارية للسجل عبر Supabase.

## التشغيل محليًا
```bash
npm install
npm run dev
```
الميكروفون يحتاج HTTPS أو localhost. للتجربة على الهاتف استخدم رابطًا HTTPS (مثل الرابط المنشور على GitHub Pages).

```bash
npm test          # اختبارات الوحدة
npm run build     # بناء الإنتاج (يفحص الأنواع أولًا)
npm run preview
```

## ما الذي يعمل
- واجهة عربية RTL متجاوبة، واختيار السورة ونطاق الآيات من AlQuran Cloud (مع فحص اكتمال عدد الآيات وترتيبها قبل بدء الجلسة).
- ثلاثة أوضاع: تسميع حر (نص مخفي)، تظليل كلمات تقريبي، ومراجعة.
- تفريغ صوتي عربي عبر Web Speech API مع إعادة تشغيل تلقائية عند السكوت، ويظهر كمعاينة فقط.
- سجل جلسات محلي (IndexedDB) ومزامنة سحابية اختيارية (Supabase).
- PWA: manifest وأيقونات وService Worker للعمل دون اتصال (هيكل التطبيق فقط).

## حدود النسخة الحالية — مهم
ليست محرك تصحيح مكتمل. التفريغ الصوتي والتظليل معاينة تقريبية ولا يُستخدمان للحكم على صحة الحفظ أو التجويد، ولا تعرض النسخة نسبة دقة مصطنعة. لا تسمح أبدًا لنموذج توليدي بإعادة إنشاء نص الآيات.

## النشر على GitHub (الكود + الموقع عبر Pages)
```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```
1. بعد أول `npm install` ارفع ملف `package-lock.json` أيضًا.
2. من المستودع: **Settings → Pages → Source: GitHub Actions**.
3. (اختياري، لتفعيل المزامنة) **Settings → Secrets and variables → Actions → New repository secret** وأضف `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY`.
4. كل `push` على `main` يشغّل `.github/workflows/deploy.yml` ويختبر ويبني وينشر الموقع.

## ربط Supabase (اختياري)
1. أنشئ مشروعًا في supabase.com.
2. **Authentication → Providers (أو Sign In / Providers) → فعّل Anonymous sign-ins**.
3. نفّذ محتوى `supabase/migrations/20261126000000_init.sql` في **SQL Editor** (أو `supabase db push` عبر الـ CLI).
4. من **Project Settings → API** انسخ Project URL ومفتاح `anon` إلى `.env.local` (انظر `.env.example`) ومحليًا، وإلى GitHub Secrets للنشر.
5. في التطبيق: صفحة السجل ← «المزامنة السحابية» ← تفعيل.

ملاحظات أمان:
- مفتاح `anon` عام بطبيعته وآمن في المتصفح لأن جدول `sessions` محمي بـ RLS. لا تضع `service_role` في التطبيق أو في المستودع أبدًا.
- الحساب المجهول مرتبط بالمتصفح: مسح بيانات الموقع أو تغيير الجهاز يفقد الوصول للسجل السحابي. لسجل يتبع المستخدم بين الأجهزة أضف تسجيل دخول (Email/Google) لاحقًا.
- لا يُرفع صوت ولا نص تفريغ، فقط بيانات الجلسة.
- Supabase هنا قاعدة بيانات ومصادقة، أما استضافة الموقع نفسه فعلى GitHub Pages (أو Netlify/Vercel).

## مصدر نص القرآن
يُحمَّل من AlQuran Cloud (`quran-uthmani`) ويُعرض كما يصل دون تعديل. قبل الإطلاق العام: راجع ترخيص المصدر، ثبّت نسخة بيانات محلية، وتحقق آليًا وبشريًا من النص والرسم وأرقام الآيات. تحقّق خصوصًا من طريقة عرض البسملة في أول آية من كل سورة في هذا المصدر.
