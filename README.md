# وَرَتِّلِ الْقُرْآنَ تَرْتِيلًا

نسخة تأسيسية (MVP scaffold) لتطبيق ويب عربي يعمل على الهواتف.

## المتطلبات
- Node.js 20 أو أحدث
- npm

## التشغيل
```bash
npm install
npm run dev
```
افتح الرابط الذي يظهر في الطرفية. لاختبار الميكروفون على الهاتف يجب استخدام HTTPS أو localhost، والسماح بإذن الميكروفون.

## البناء
```bash
npm run build
npm run preview
```

## الموجود حاليًا
- واجهة عربية RTL متجاوبة.
- اختيار السورة ونطاق الآيات من واجهة AlQuran Cloud API.
- أوضاع التسميع الثلاثة (واجهة اختيار وعرض).
- تفعيل مبدئي للتعرف على الكلام العربي عبر Web Speech API في المتصفحات الداعمة.
- حفظ سجل الجلسات محليًا باستخدام IndexedDB.
- PWA Service Worker وملف manifest.

## حدود النسخة الحالية — مهم
هذه ليست نسخة إنتاجية مكتملة لمحرك التصحيح. التفريغ الصوتي الظاهر هو معاينة للتعرف على الكلام فقط، ولا يُستخدم لإصدار حكم على صحة الحفظ أو التجويد. لم يتم بعد ربط محرك مقارنة قرآنية موثوق أو نموذج صوتي متخصص في التجويد أو مكتبة تسجيلات قراء مرخصة. لذلك لا تعرض النسخة درجة دقة مصطنعة ولا تصنف التجويد تلقائيًا.

## مصدر نص القرآن
تُحمّل السور من AlQuran Cloud API باستخدام إصدار quran-uthmani. قبل الإطلاق العام يجب مراجعة ترخيص المصدر، تثبيت نسخة بيانات محددة، والتحقق آليًا وبشريًا من النص والرسم وأرقام الآيات. لا تسمح أبدًا لنموذج توليدي بإعادة إنشاء نص الآيات.

## الخطوات التالية
1. اعتماد مصدر نص قرآني وترخيصه وتثبيت بياناته.
2. إضافة اختبارات سلامة النص وعدد الآيات وترتيبها.
3. بناء Backend لمعالجة الصوت مع حماية مفاتيح API.
4. ربط محرك ASR عربي مع محرك محاذاة/مطابقة خاص بالقرآن.
5. إضافة نموذج تجويد متخصص وتقييمه على عينات تلاوة معتمدة.
6. إضافة تسجيلات قراء مرخصة مع تخزين مؤقت وإعادة تشغيل.
7. اختبار الأداء والخصوصية وإمكانية الوصول على Android وiOS.

## الخصوصية
سجل الجلسات محلي على الجهاز. لا يتم رفع التسجيلات من هذه النسخة إلى خادم. واجهة التعرف الصوتي قد تعتمد على مزود المتصفح؛ راجع إعدادات الخصوصية في المتصفح.
